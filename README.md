# ГЕЛИКС

Публичный сайт архитектурно-инжинирингового бренда: [esvdox.github.io/geliks](https://esvdox.github.io/geliks/).

Главная, семь страниц направлений и форма подготовки брифа. Форма формирует текстовый файл в браузере. Визуализации иллюстрируют направления и не являются фотографиями реализованных объектов.

Сборка без внешних зависимостей: `node build.mjs`. Для обновления текстов и структуры см. `content.mjs` и `build.mjs`. Стили, интерактив и изображения лежат в `docs/assets/`. GitHub Pages публикует папку `docs` ветки `main`.

Локальная проверка: `node scripts/verify.mjs`.
